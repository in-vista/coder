Here you can add theme's for wiser sub domains. Simply add a css file with the same name as the subdomain you want to use it for. You can overwrite any default Wiser CSS in that file.
Logo's must by Base64 data with a format of max 300x60 px

When adding a new CSS-file, make sure to set the "Copy to output directory" of the file's properties to "Copy always". If skipping this step, the CSS will not be included in the build of the project.
